# rust-template

> *NOTE*: This README has been completely generated by an AI, because I felt lazy. It is just a template, who cares.

A small Rust REST API template built with [Axum](https://github.com/tokio-rs/axum), [Tokio](https://tokio.rs) and the [MongoDB](https://www.mongodb.com/docs/drivers/rust/) driver. It exposes a generic CRUD endpoint for JSON documents and health probes for Kubernetes-style deployments.

This is a starting point, meant to be modified and improved for your own project.

## Endpoints

| Method | Path       | Description                                   |
| ------ | ---------- | --------------------------------------------- |
| GET    | `/`        | List documents (`?limit=` 1–100, `?skip=`)    |
| POST   | `/`        | Store a JSON body, returns the new `_id`      |
| GET    | `/{id}`    | Get one document by id                        |
| DELETE | `/{id}`    | Delete one document by id                     |
| GET    | `/livez`   | Liveness probe (also `/healthz`)              |
| GET    | `/readyz`  | Readiness probe (pings MongoDB)               |

The server listens on `0.0.0.0:3000`.

## Prerequisites

- Rust (edition 2024, so a recent stable toolchain)
- Docker, to run MongoDB locally

## Running it

1. Start MongoDB:

   ```bash
   docker compose -f .dev/docker-compose.yml up -d
   ```

2. Create your environment file from the example:

   ```bash
   cp .env.example .env
   ```

   The variables are:

   - `MONGODB_CONNECTION_STRING`: MongoDB connection string (required)
   - `CONFIGURATION_FILE`: path to the JSON config (default `./config.json`)
   - `LOG_LEVEL`: log filter, e.g. `info` or `debug`

3. Run the API:

   ```bash
   cargo run
   ```

4. Try it:

   ```bash
   curl -X POST localhost:3000/ -H 'Content-Type: application/json' -d '{"name":"ferris"}'
   curl localhost:3000/
   curl localhost:3000/readyz
   ```

Stop with `Ctrl+C`. The server shuts down gracefully.

## Configuration

`config.json` (see `.dev/config.json` for an example) sets the database and collection used by the object API:

```json
{
    "api": {
        "object": {
            "database": "rust-api",
            "collection": "favorites"
        }
    },
    "metrics": {
        "enabled": true
    }
}
```

Copy it to the project root, or point `CONFIGURATION_FILE` at it.
